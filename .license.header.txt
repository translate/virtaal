A `#!/usr/bin/env python` shebang may appear directly above this block
on `setup.py`, the one `.py` file that's actually run directly
(`./setup.py build`, see docs/building.rst) - don't add one anywhere
else (see PR #3430; almost no file here is run directly, so a shebang
on it is just noise). The header check tolerates an optional shebang
line before the block, it doesn't require its absence.
