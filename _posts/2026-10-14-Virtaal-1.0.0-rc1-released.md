The release candidate for Virtaal 1.0.0 - what we intend to release as
1.0.0 unless testing turns up something serious. See the
[release notes](https://docs.translatehouse.org/projects/virtaal/en/latest/releases/1.0.0.html)
for what's new, and please
[report anything that goes wrong](https://github.com/translate/virtaal/issues).

The macOS builds are signed and notarized by Apple, and the Windows
installer is signed by Translate House Ltd. Windows may still show a blue
"Windows protected your PC" screen for a while, until SmartScreen
recognises the new certificate: click **More info**, then **Run anyway**.

The interface text is now frozen for 1.0.0, so this is the time to
translate it: [Translate Virtaal](/translate.html) shows how far each
language has got and how to send in a translation.
