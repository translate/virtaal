---
title: Virtaal 1.0.0-rc3 Released
category: releases
---

The third release candidate for Virtaal 1.0.0. It fixes the problems
testers found in rc2: installing over Virtaal 0.7 on Windows, spell
checking and autocorrect for more languages, and machine translation
suggestions. It also brings updated translations. See the
[release page](https://github.com/translate/virtaal/releases/tag/v1.0.0-rc3)
for what's new since rc2, and please
[report anything that goes wrong](https://github.com/translate/virtaal/issues).

The interface text is still frozen for 1.0.0. Translations sent in by
21 November ship in 1.0.0: [Translate Virtaal](/translate.html) shows how
far each language has got and how to send one in.
