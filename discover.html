Discover Virtaal

Virtaal is a translation tool built around one idea: keep the interface out of your way and let you focus on the actual translation.

Every format, one interface

PO, XLIFF, TMX, TBX, Qt Linguist (.ts/.qph), Fluent, and compiled Gettext MO catalogs, all through the Translate Toolkit - no format-specific tool switching.

Translation memory built in

Suggestions from your own past translations as you work, with support for pulling in memory from other projects too.

Quality checks as you go

Catches common mistakes - mismatched variables, punctuation, accidentally-translated placeables - before they reach your translation, not after.

Terminology assistance

Consistent terms across a whole project, surfaced right where you're translating.

Keyboard-driven workflow

Navigate, search, and manage translation states without reaching for the mouse.

Runs everywhere

Linux, Windows, and macOS, with the same feature set on each.
