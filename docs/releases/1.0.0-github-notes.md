Virtaal is back. After being dormant since 2020, it's been rebuilt from
the ground up on Python 3 and GTK 3, and is once again a maintained,
actively-developed translation tool.

> **Unsigned binaries**: macOS and Windows builds aren't code-signed yet, so
> Gatekeeper/SmartScreen will warn on first launch.
> - **macOS**: right-click (or Control-click) `Virtaal.app` and choose
>   **Open** - a plain double-click will refuse outright the first time.
>   If it instead says the app is damaged, run `xattr -cr /path/to/Virtaal.app`
>   in Terminal first.
> - **Windows**: click **More info**, then **Run anyway** on the
>   "Windows protected your PC" screen.

## What we set out to do

A handful of things drove this release, in order of priority:

1. **Don't break the translating experience translators already know.** Virtaal's appeal has always been that it gets out of the way and lets you translate - a rewrite of its internals was never licence to also rewrite its workflow.
2. **Port to a modern windowing system** before the old one disappears from under us entirely, and use that as the moment to bring the rest of the engine (Python itself included) up to date too.
3. **First-class builds on every platform** - Windows, macOS and Linux should each get a real, native-feeling installer, not one platform treated as primary and the others as an afterthought.
4. **Seamless download of resources when you need them** - dictionaries, autocorrect rules and similar data shouldn't have to be bundled upfront or hunted down by hand; Virtaal should fetch what a given language needs, on demand, and stay out of your way while doing it.
5. **Make it feel like it belongs on your computer**, not like a cross-platform app that merely runs there.
6. **Make it something you can trust with your work** - it shouldn't lose translations, corrupt files, or leave you guessing why it froze.

## How we met them

**Same Virtaal, modern engine.** The move from Python 2/GTK 2 to Python 3/GTK 3 touched almost every file in the codebase, but day-to-day translating - opening a file, moving between units, matching against translation memory, running quality checks, spell-checking - works the same way it always has. If you used Virtaal before 2020, you don't need to relearn anything; the windowing system underneath changed, the tool you sit down to use didn't.

**First-class on every platform.** All three platforms now get a real, proper build: a Windows installer with correct file associations and icons, native macOS `.app`/`.dmg` builds for both Apple Silicon and Intel, and a Flatpak for Linux - built, tested and shipped from the same CI pipeline rather than one platform being the "real" build and the others best-effort ports.

**Resources arrive when you need them.** Dictionaries, autocorrect rules and similar per-language data are fetched automatically the first time you need them for a given language, rather than needing to be bundled for every language upfront or tracked down and installed by hand. Once fetched, they're cached, so you only pay that download cost once per language.

**Feels native on your platform.** Rather than a single cross-platform look, Virtaal now leans into each OS's own conventions: real native Open/Save dialogs instead of GTK's own file picker, macOS keyboard shortcuts (Cmd instead of Ctrl) throughout, a title bar that follows each platform's own naming and "unsaved changes" conventions, a populated macOS Dock menu with recent files, and light/dark theme switching that follows your system live instead of only at startup.

**Built to be trusted.** A sustained focus on correctness and crash-hardening runs through this release: fixes for several ways Virtaal could previously crash outright (corrupt settings files, certain file formats, specific edit sequences), a more careful undo/redo model so navigating around no longer muddies what "undo" actually undoes, read-only files are now handled safely instead of inviting a crash on save, and network requests (translation memory, terminology, dictionary downloads) now fail cleanly with a timeout instead of hanging Virtaal indefinitely. There's also a built-in crash dialog with a one-click bug report button for whatever we haven't caught yet.

**Easier to use in your own language.** Virtaal's own interface can now be switched independently of your system language, from Preferences or via a command-line flag - and a long-standing bug that silently broke interface translations in the installed build entirely is fixed. The Windows installer also now offers substantially more UI languages to choose from during setup.

## Known limitations

Nothing release-blocking, but worth knowing about:

- No spell checking in the Apple Silicon macOS build (the Intel build has it) - the underlying spell-check library has no ready-made build for that platform yet.
- A small number of complex scripts (e.g. Amharic) may not render correctly in the Windows build, most likely a font-coverage gap rather than a deeper text-handling issue.
- Occasionally, selecting "Incomplete" from the navigation dropdown right after launch doesn't switch modes on the first try - selecting it again, or picking any other mode first, works.
