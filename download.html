Download Virtaal

The latest version is {{ site.latest_version }}. On the release page, download the file for your computer:

  • Windows: virtaal-{{ site.latest_version }}-setup.exe
  • Mac with Apple silicon (M1 and later): Virtaal-macos-arm64.dmg
  • Mac with an Intel processor: Virtaal-macos-x86_64.dmg
  • Linux: Virtaal-linux-x86_64.flatpak, or Virtaal-linux-aarch64.flatpak for ARM

The macOS builds need {{ site.macos_minimum }} or later. On Linux, install the Flatpak with flatpak install --user Virtaal-linux-x86_64.flatpak, using the file name you downloaded. Install each new release the same way.
